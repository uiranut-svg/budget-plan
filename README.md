# ระบบข้อมูลแผนงานและงบประมาณ

เว็บเผยแพร่แผนงานและงบประมาณประจำปีของสถานศึกษา: สรุปงบรายปี, กราฟ, รายละเอียดรายการ/หน่วยงาน, เปรียบเทียบรายปี และเล่มแผน PDF แบบพลิกหน้า (E-book)

## ติดตั้ง
1. วางโฟลเดอร์ในเว็บเซิร์ฟเวอร์ (ตั้งชื่อโฟลเดอร์อะไรก็ได้) — PHP 5.4 ขึ้นไป + MySQL/MariaDB 5.5 ขึ้นไป
2. ให้เว็บเซิร์ฟเวอร์เขียนโฟลเดอร์ `inc/` (ตอนติดตั้ง) และ `files/books/` ได้ (Linux: `chown -R apache <โฟลเดอร์>`)
3. เปิด `setup.php` จากเครื่องเซิร์ฟเวอร์ (เครื่องอื่น: ใส่ IP ในไฟล์ `inc/setup.allow`)
4. Apache ต้องเปิด `AllowOverride All` ให้ `.htaccess` ทำงาน (ปิด `inc/` และกันสคริปต์ใน `files/`) · nginx ต้องปิด `inc/` เอง
5. อัปโหลดไฟล์ใหญ่: ปรับ `upload_max_filesize` / `post_max_size` ใน php.ini
